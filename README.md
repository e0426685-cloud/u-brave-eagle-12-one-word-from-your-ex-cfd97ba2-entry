Entry for the make.fun bounty **"One Word From Your Ex"** — submit exactly
one word an ex would use to describe the entrant.

## The word

**placeholder** — the most painfully honest one-word verdict an ex can
deliver. You thought you were the one; you were a placeholder.

## How it works

`main.py` (Python 3, standard library only) writes the word to
`/output/entry.txt` — 1–24 characters, exactly one word — with mode 644
so the grader can read it.

```sh
python3 main.py
```
